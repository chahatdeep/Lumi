Lithophane & 3D model maker

Photos that glow.

Lumi turns any picture into a 3D-printable lithophane: a thin sheet of plastic that shows your photo when light shines through it. Make flat panels, curved frames, lamps and moon globes, and export meshes your slicer opens instantly.

Make your lithophane

This is the real Lumi lithophane engine, running entirely in your browser. Drop in a photo, shape it, then export an STL. Your image is never uploaded anywhere.

Lumi · lithophane maker Open full screen ↗
  1. ImageOpen, drop or paste (Ctrl+V) a photo, or start from a quick template.

  3. ModelPick a shape, size, thickness and outline, then add a frame, stand or hanger.

Features

Everything a good lithophane needs

Five shapes

Flat panels, curved frames, cylinder lamps, n-sided prism lamps and moon globes with top and bottom openings.

Outlines & frames

Rectangle, rounded, oval, heart, hexagon, octagon, star or arch, with beveled, flat or rounded frames.

Ready-made accessories

Stand and base, hanging loop, nightlight holder, lamp fitting and connectors, built into the same watertight mesh.

Photo editing built in

Crop, rotate, auto levels, brightness, contrast, gamma, shadows and highlights, smoothing, sharpening, edge fade, invert, and text.

Light-accurate thickness

Choose a linear or light-accurate tone curve and set the filament opacity, then preview the print backlit before you print.

Slicer-friendly exports

A QEM optimizer merges triangles in flat and smooth areas with a capped triangle count, so the mesh stays watertight and loads instantly.

Desktop app · Windows

More in the desktop app: Pop 3D

The Windows app has everything above, plus Pop 3D, which turns a single photo into a printable 3D model. Use an AI depth relief, or full 3D generation on your own NVIDIA GPU (Hunyuan3D-2, offline) or through free Hugging Face Spaces. It can also repair and optimize an existing STL, OBJ or GLB.

Build & run it

You need Windows 10 or 11, Node.js 20+ and Git. An NVIDIA GPU is optional, for offline Pop 3D.

npm run dist creates an installer and a portable .exe in dist/. The README covers troubleshooting and build gotchas.

View on GitHub 
# get the code
git clone https://github.com/chahatdeep/Lumi.git
cd Lumi
npm install

# run it
npm start

# build the Windows installer + portable exe
npm run dist

Print tips

Getting a great print

100% infillThe walls are the image.
0.08–0.12 mm layersThinner layers give smoother tones.
White PLAThen match Filament opacity in Lumi.
Print uprightGives the smoothest tones. Add a 5 mm brim for tall prints.
Slow outer wallsAround 40 mm/s to avoid wobble.
Backlight itA warm LED behind the print brings the photo to life.
